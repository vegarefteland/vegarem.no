All archive images go here.

Naming: sequential numbers, padded to two digits.
  01.webp
  02.webp
  03.mp4
  ...

Keep the numbering continuous — no gaps. Opened straight from Finder
(file://) the site finds archive files by counting up, and stops at the
first missing number. Online it reads images/manifest.json, which doesn't
care, but continuous is safest.
Supported formats: webp, jpg, png, gif, mp4
